<objective>
Write down the deferred-measurement contract as this theme's own specification, and make a command
fail when the code and that specification disagree.

Purpose: SHELL-04 exists because "Etapa 2 connects without a refactor" is a promise that can only be
kept if the shape of the connection is written down before anyone builds against it. The event names
this theme publishes, the cart attributes the orders have to carry, and the funnel event types the
collection endpoint accepts are three vocabularies owned by three different places — a theme, a
browser script in another repository, and an edge function. This plan puts all three in one document
that belongs to the theme, and then does what this repository already does twice over: turns the
document into a check that fails.

Output: `ETAPA-2-SEAMS.md`, the seams checker, both wired into the local lint chain and the required
CI gate, and the reasoned declaration that this phase integrates no external API.
</objective>

<decisions>
Planner-resolved questions this plan implements. Veto any of these at plan review.

- **The document is hybrid: the contract inline, the sibling files cited as its origin** (D-04). A
  document that only links out is worthless the day the sibling repository is renamed or made
  private; a document that only restates is worthless the day the sibling changes. Both: transcribe,
  and cite what was transcribed from.
- **The seventh cart attribute is assigned to Etapa 2, and the document says so out loud.** The
  sibling script writes six today. Rather than pretending it writes seven or leaving a blank, the
  document records the gap, names the two possible owners — a theme snippet reading the view
  parameter, or an updated sibling script — and marks it as a decision Etapa 2 or Phase 10 closes.
  An acknowledged gap is a seam; an unacknowledged one is the refactor this phase exists to prevent
  (research Pitfall 5).
- **Every contract token appears inside backticks in the document.** That is what makes the checker
  deterministic rather than fuzzy: a seven-letter word like the view parameter appears in ordinary
  prose all over a document about views, but only the code-formatted occurrence is the contract.
- **The checker reads the published name list out of the module rather than restating it.** A
  checker that keeps its own copy of the names is a third place for them to drift.
</decisions>
