## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| github.com/Shopify → local git remotes | An `upstream` remote is a code source a future maintainer may merge from |
| planning documents → every future agent | `.claude/CLAUDE.md` is loaded as instructions by every agent in this repository |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-04 | Spoofing | `upstream` git remote | medium | mitigate | Prohibition against pointing `upstream` at a fork or mirror; acceptance criterion asserts the official repository URL; `git remote -v` asserted to hold exactly one `upstream` pair |
| T-01-05 | Tampering | `.claude/CLAUDE.md` instruction file | medium | mitigate | Only the `GSD:project-start` block content is edited; the start/end markers are asserted still present so no block boundary is silently dissolved |
| T-01-06 | Repudiation | Undocumented divergence from the starter | medium | mitigate | `OVERRIDES.md` ledger with a stated rule that divergences land in the same pull request; pinned base tag gives every future diff a fixed reference point |
</threat_model>
